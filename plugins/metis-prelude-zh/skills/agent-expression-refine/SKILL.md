# Agent 中文表达优化

将中文 Agent 输出改写为直接、准确的技术表达。保持事实、数字、结论强度、确认状态和适用范围不变。

## 工作流程

1. 识别非标准术语、比喻、口语、拟人、对比句式和带倾向性的标签。
2. 根据下列规则改写，不增加原文未提供的分析、数字、原因或结论。
3. 检查术语、章节状态标签和不确定性表述是否一致。
4. 遵循用户指定的输出形式。用户仅要求润色时，只返回改写后的文本。

## 基本约束

- 保留技术含义、因果强度和证据边界。
- 优先使用领域内已有的标准术语。标准术语与本 skill 的示例冲突时，采用当前领域的标准术语。
- 原因未经确认时，写“原因未查明”。不要补充假设性解释。
- 不要求每个表格条目都包含数字、比较或结论。信息完整即可。

## 规则 1：使用标准术语

已有通用说法的概念不要另造表述。

| 原表述 | 改写 |
| --- | --- |
| 超长度 | 截断 |
| 超不超长度 | 是否触及长度上限 |
| Ray 的端口会跟自己撞 | 多个任务的 Ray 抢占同一端口 |
| 臂 | 方案 |
| 只看长度那条线 | 长度启发式基线 |
| 刷奖励 | 奖励被优化但评测指标未改善 |
| 存档 | checkpoint |

## 规则 2：不发明比喻作为术语

如果一个说法需要读者推断其指代对象，直接说明对象、变化和结果。

| 原表述 | 改写 |
| --- | --- |
| 血统 | 基座来源 |
| 8 个不同血统 | 8 个不同基座的模型 |
| 那是尺寸差异，不是血统差异 | 原有区间由 Qwen 的 14B、32B、72B 构成，差异来自参数量而非基座 |
| 已经吃掉一半空间 | 已覆盖一半区间 |
| 变成了一个认题目的检索器 | 退化为问题识别，与学习价值无关 |
| 挑出来的题目看上去健康得多 | 选中问题的截断比例更低 |
| 误差范围还盖着基准线 | 置信区间与基线重叠 |

## 规则 3：使用中性的表头、分类名和状态标签

使用描述内容类型或事实状态的名词。

| 原表述 | 改写 |
| --- | --- |
| 坑 | 问题 |
| 代价和教训 | 影响 |
| 把握 | 确认程度 |
| 怎么做的 | 实验设置 |
| 重挑一次还剩多少重合 | 重采样后的重合率 |
| 有几种不同取值 | 取值数量 |
| 还在跑的 | 进行中 |
| 一个必须关掉的开关 | 需要关闭的过滤器 |

保持章节状态标签一致。前文采用以下标签时，后文继续使用同一组标签：

- 已完成
- 已确认
- 未达到基线
- 结论待定

后文出现“做通了”“意外发现”“需要修”“没有买到想要的”等临时表述时，根据已陈述的事实选择前文已有的中性标签。不要新增另一组状态标签。

## 规则 4：不使用“是 X，不是 Y”的对比句式

直接陈述检查结果、指标关系或观察到的差异。

| 原表述 | 改写 |
| --- | --- |
| 梯度对齐：是噪声，不是信号 | 梯度对齐：三项检查结果均在噪声范围内 |
| 我们买到了血统上的多样性，但没有买到能力上的多样性 | 新增模型覆盖了更多基座，但正确率均低于原有区间下界 |
| 考法和用法对不上 | 评测口径为成对比较，与实际使用方式不一致 |
| 稳定是靠粗糙换来的 | 取值数量少的指标重合率高 |
| 越稳定的指标越挑不出东西，越挑得出东西的指标越不稳定 | 重合率与取值数量呈反向关系 |

## 规则 5：允许条目只说明发生了什么

信息已经完整时停止，不为格式对称而补充数字、比较或结论。

示例：

> 对照组为随机选取的 32 个问题。

这条内容已经完整，无需补充其他方案与对照组的关系。

## 规则 6：明确标注未查明的原因

原因未得到验证时，写“原因未查明”。前文已经使用该表述时，后文不要补充未经验证的解释。

| 原表述 | 改写 |
| --- | --- |
| 这可能也解释了前文那个现象 | 该现象与截断的关系尚未验证 |

来源文本明确说明机制已经查明时，可以保留确认后的解释。例如，第十章“后来查明了机制”之后的内容可以保留。

## 规则 7：不使用口语词

使用可以直接核对的数字、统计概念和实验描述。

| 原表述 | 改写 |
| --- | --- |
| 赢得很干脆 | 差值为 0.030 |
| 测得更准 / 测得更糙 | 估计精度更高 / 更低 |
| 可选的余地很小 | 候选范围小 |
| 基本上等于抓阄 | 接近随机选取 |
| 本来就分不出高下 | 真实差距低于可分辨范围 |
| 白跑 / 白占 | 无效运行 / 空占 |
| 不是白捡的 | 需要 79 GPU·小时 |
| 一个致命问题 | 主要问题 |
| 有事后找补的嫌疑 | 该切分方式在观察结果之后确定 |
| 原因不复杂 | 删除 |
| 既然预测这条路走不通，那就退一步 | 删除，直接进入实验设置 |

## 规则 8：不使用拟人表述

明确写出指标、过程、条件和变化。

| 原表述 | 改写 |
| --- | --- |
| 天生需要几百到上千次采样 | 该信号所需的采样量为几百到上千次 |
| 一旦超就制造出参差 | 截断发生时会增大奖励方差 |
| 24 步训练只挪动 0.05 | 24 步训练后正确率变化为 0.05 |
| 超得越彻底反而越稳定 | 截断率越高，奖励方差越低 |
| 回答内容本身的好坏参差 | 答案质量的差异 |

## 完成检查

- 术语采用领域内通用说法。
- 指代对象、指标和关系均已直接说明。
- 表头、分类名和状态标签保持中性且前后一致。
- 文本不含自造比喻、口语、拟人或“是 X，不是 Y”对比结构。
- 未查明的原因仍标记为“原因未查明”。
- 没有添加来源文本不支持的数字、比较、原因或结论。
- 改写前后的事实、结论强度和确认程度一致。
